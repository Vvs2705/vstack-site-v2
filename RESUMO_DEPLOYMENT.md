## 📞 SUPORTE RÁPIDO

Checklist do que fazer se algo der errado:

| Problema | Solução |
|----------|---------|
| Build falha | Verificar logs no Vercel Dashboard |
| DNS não propaga | Aguardar 24-48h ou testar em whatsmydns.net |
| Email não chega | Verificar registros SPF/DKIM/DMARC |
| Site lento | Rodar Google PageSpeed Insights |
| Erro 404 em página | Verificar rotas em next.config.ts |
